# Боевой магазин размещается на облачном сервере reg.ru, а не на Vercel

**Статус:** решение пользователя — домен и хостинг на reg.ru. Тариф рекомендован, покупка ещё не сделана.

**Почему облачный сервер (VPS), а не виртуальный хостинг reg.ru:** нужен постоянно работающий Node.js (Next.js-сервер + вебхук бота). Официальной поддержки Node на виртуальном хостинге reg.ru не нашлось.

**Почему не Vercel:**
- в 2026 массовые жалобы: сайты на Vercel с собственным доменом не открываются из России без VPN или обрывают ответ;
- бесплатный тариф Hobby — только некоммерческий; Pro $20/мес, оплата из РФ только через посредников;
- имена и телефоны покупательниц окажутся за рубежом — нарушение 152-ФЗ (локализация ПДн).
- Облачная Supabase — те же вопросы с 152-ФЗ и оплатой.

**Рекомендованная схема (всё на одном сервере):**
- Ubuntu 24.04, nginx + Let's Encrypt, Next.js под systemd/pm2;
- облегчённая самостоятельная Supabase: только Postgres + PostgREST + Storage API (коду больше ничего не нужно), без Kong/Realtime/Auth/Studio; плюс swap;
- бот через вебхук `/api/telegram/webhook`.

**Тариф и цены (страница reg.ru, ноябрь 2026, перепроверять в конфигураторе):**
- Std C2-M2-D40 (2 vCPU, 2 ГБ, 40 ГБ SSD) ≈ 980 ₽/мес — рекомендован;
- High C2-M4-D60 (4 ГБ) ≈ 2 180 ₽/мес — пользователю «накладно»;
- домен .ru — 169 ₽ первый год (акция до 31.12.2026), продление 999 ₽/год.

**Что сделает пользователь:** купит домен и сервер; перед созданием сервера Claude генерирует SSH-ключ, пользователь вставляет публичную часть в форму reg.ru. Дальше Claude настраивает всё сам.

**Не забыть:** уведомление в Роскомнадзор как оператор ПДн (онлайн, бесплатно).
