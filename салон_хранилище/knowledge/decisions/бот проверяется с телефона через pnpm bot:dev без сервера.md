# Бот проверяется с телефона через pnpm bot:dev без сервера

**Решение:** `scripts/bot-dev.ts` запускает бота long polling'ом (`bot.start()`), вебхук и публичный адрес не нужны. Данные — в локальной Supabase.

**Что делает скрипт:**
- без `TELEGRAM_BOT_TOKEN` печатает инструкцию для @BotFather;
- без Supabase (`isDemo`) — просит `supabase start`;
- если у бота был вебхук — снимает и предупреждает вернуть `pnpm bot:set-webhook`;
- ставит команды `/start`, `/help`; при пустом `OWNER_TELEGRAM_IDS` подсказывает узнать ID через `/start`.

**Ограничения:**
- бот живёт, пока жив процесс (в сессии Claude — фоновая задача; закрыли — бот молчит);
- фото товаров в карточках бота не видны: Telegram не достаёт до `127.0.0.1:54321`, карточка уходит текстом;
- кнопки-ссылки на сайт скрыты, см. [[Telegram отклоняет кнопки-ссылки на localhost]];
- товары с ноутбука на живой сайт не попадают, см. [[витрина публикуется на GitHub Pages статической сборкой]].

**Перезапуск после правки кода:** tsx без watch — остановить процесс (`pkill -f scripts/bot-dev.ts`) и снова `pnpm bot:dev`. Два процесса одновременно дадут `409 Conflict`.
