# Дизайн LUNARA — редакционный бутик в терракоте с мотивом арки

**Палитра** (токены в `app/globals.css`, hex в компонентах не пишем):
- `terracotta` #A84A24 — на нём cream даёт контраст 4.95:1
- `brown` #4A2C21
- `espresso` #2A1810 — основной текст
- `cream` #F6EEE4 — фон
- `sand` #ECDCC9 — подложка фото
- `clay`, `ivory`

**Шрифты:** Jost 300 uppercase для огромных заголовков, Cormorant Garamond italic для акцентов и названий товаров.

**Фирменный мотив:** арка (`.arch`). Это отсылка к марокканским аркам на упаковке La Sultane de Saba.

**Фото:** packshot'ы с белым фоном лежат на песке с `mix-blend-multiply`, белый фон исчезает. Упаковка бренда сама терракотовая, поэтому всё сочетается.

**Что взяли из референсов:**
- skincareagents: огромные тонкие заглавные, круглые CTA, бегущая строка, вращающийся бейдж, блоки 01/02/03, список с превью за курсором, коллаж;
- cosmetos: вкладки «Новинки · Хиты · Скидки», бейджи, чипсы-фильтры (у нас по ароматам).

**Анимации** (`components/motion/`, все через `motion` и `MotionConfig reducedMotion="user"`):
- reveal строк из маски;
- магнитные кнопки;
- marquee, которая ускоряется от скорости скролла (основа — 21st.dev magicui);
- превью за курсором со skew (основа — 21st.dev educalvolpz);
- полёт товара в корзину;
- SVG-линия, которая рисуется при скролле;
- параллакс.

**21st.dev:** на бесплатном тарифе даёт только 2 компонента в день.
