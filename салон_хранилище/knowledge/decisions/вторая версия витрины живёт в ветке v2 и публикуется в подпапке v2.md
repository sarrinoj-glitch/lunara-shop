# Вторая версия витрины живёт в ветке v2 и публикуется в подпапке v2

**Запрос пользователя (2026-11-16):** «все подряд на втором билде» — добавить все 17 предложенных улучшений из shadcn, 21st.dev и motion отдельной второй версией, чтобы сравнить с первой.

**Обновление 2026-11-16:** пользователь выбрал v2 основной. Ветка `v2` влита в `main` и открывается по главному адресу. Первая версия сохранена git-тегом `v1`. Адрес `/v2/` теперь перенаправляет на главную (страница-редирект создаётся в `pages.yml`). Workflow снова собирает только `main`.

**Как было до слияния:** ветка `v2`, адрес `…/lunara-shop/v2/` (noindex), workflow собирал `main` в корень и `v2` в `/v2/`.

**Что добавлено:**
- **Глобально:** интро (монограмма L, буквы, шторка; один раз за сессию, без JS прячется CSS-ом); курсор-кольцо с подписями `data-cursor`; полоса прогресса в шапке; перелёт фото карточка → страница товара через React `ViewTransition` (`productVT(slug)`).
- **Главная:** «LUNARA в цифрах» (CountUp); 3D-наклон с бликом на категориях (`Tilt`); «Ритуал хаммама в 4 шага» (StackingCards с 21st.dev); «Путешествие по ароматам» — горизонтальная галерея с закреплением (на мобиле snap-лента); манифест с проявлением слов при прокрутке; тёплые пятна света и наклон арки в hero.
- **Каталог:** быстрый просмотр (Dialog на десктопе, vaul Drawer на телефоне); кнопка «В корзину» с превращением в галочку (`AddToCartButton`); FLIP-перестановка при фильтрах (`layout` + `AnimatePresence popLayout`); поиск ⌘K (cmdk, `CommandDialog` — содержимое нужно оборачивать в `<Command>`).
- **Товар и корзина:** лупа (учитывает внутренний отступ фото 10%); полноэкранная галерея со свайпом; катящиеся цифры (`RollingText`); корзина на телефоне снизу (Drawer).

**Подводные камни:**
- 21st.dev на бесплатном тарифе отдаёт 2 компонента в день, поэтому проявление слов написано вручную.
- Инструмент наведения в эмулированном окне не шлёт `pointerover`, и лупа там не видна. Проверено настоящими PointerEvent.
- Проверять только опубликованный сайт, не localhost (просьба пользователя).
