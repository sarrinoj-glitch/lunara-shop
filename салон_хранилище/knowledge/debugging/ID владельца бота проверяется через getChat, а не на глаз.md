# ID владельца бота проверяется через getChat, а не на глаз

**Ситуация 1:** пользователь сказал «написал боту», но `getUpdates` был пуст, вебхука нет, других polling-процессов нет. Вероятно, сообщение ушло другому боту или было отправлено раньше суток назад (Telegram хранит непрочитанные апдейты 24 ч). Со второй попытки по прямой ссылке t.me/… всё пришло.

**Как ловить ID без запущенного бота:** фоновый цикл `getUpdates?timeout=50` (без `offset`, чтобы не подтверждать апдейты), из первого приватного сообщения взять `from.id`. Пока работает `pnpm bot:dev`, `getUpdates` вызывать нельзя — `409 Conflict`.

**Ситуация 2:** ID владелицы пришёл размытым скриншотом. Перед записью в `OWNER_TELEGRAM_IDS` проверен через `getChat?chat_id=<id>`: вернул приватный чат с ожидаемым именем → цифры прочитаны верно. `getChat` работает, только если человек уже писал боту, и ничего ему не отправляет.

**Правило:** ID в публичное хранилище и в git не пишем — только в `.env.local`.
