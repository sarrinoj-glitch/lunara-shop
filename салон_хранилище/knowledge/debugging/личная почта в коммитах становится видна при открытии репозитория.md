# Личная почта в коммитах становится видна при открытии репозитория

**Проблема:** все коммиты были подписаны личной gmail пользователя. Когда репозиторий стал публичным ради GitHub Pages, почту увидел бы любой.

**Что сделали до открытия:**
- в локальном `git config` (только для этого репозитория) задан `user.email = 271080082+sarrinoj-glitch@users.noreply.github.com`;
- история переписана: `git rebase --root --exec 'git commit --amend --no-edit --reset-author'`, потом `push --force-with-lease`;
- проверка: `git log --format='%ae' | sort -u` выдаёт только noreply.

**Правило на будущее:** перед тем как открывать любой репозиторий, проверить авторов коммитов.

Связано с [[витрина публикуется на GitHub Pages статической сборкой]].
