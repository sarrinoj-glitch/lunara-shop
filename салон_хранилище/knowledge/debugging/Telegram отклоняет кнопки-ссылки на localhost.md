# Telegram отклоняет кнопки-ссылки на localhost

**Риск (найден при чтении кода перед запуском, в этой сессии не воспроизводился):** при локальном `NEXT_PUBLIC_SITE_URL=http://localhost:3000` карточка опубликованного товара содержит inline-кнопку `🔗 На сайте` с URL на localhost. Bot API не принимает такие URL в кнопках, `sendMessage` с карточкой упал бы → бот написал бы «Ой, что-то пошло не так».

**Второе проявление (увидел пользователь):** после публикации бот писал «Товар уже на сайте» со ссылкой `http://localhost:3000/...`, которая с телефона не открывается.

**Решение:**
- `lib/bot/render.ts`: кнопка-ссылка только если `publicEnv.siteUrl` начинается с `https://`;
- `lib/bot/bot.ts`: без https после публикации текст `B.add.publishedLocal` — «Товар сохранён… на живом сайте появится, когда бот переедет на сервер».

См. [[бот проверяется с телефона через pnpm bot:dev без сервера]].
